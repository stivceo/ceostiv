## How to Deploy

### Option A: Vercel (Instant Deploy)

1. Go to [https://vercel.com](https://vercel.com)
2. Create an account and drag the ZIP folder
3. Boom — it's live.

### Option B: GitHub Pages

1. Create a new GitHub repository
2. Upload `index.html` and `stiv-logo.png`
3. Go to Settings > Pages > Source: `main` branch > Save
4. Done. Your site is public.
